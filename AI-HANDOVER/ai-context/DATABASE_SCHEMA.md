# 数据模型说明



# 1. Source


用途：

记录新闻来源。



主要信息：


来源名称。

来源地址。

来源类型。

可信度。



注意：

新增来源必须评估质量。



================================

# 2. News


用途：

核心新闻数据表。



保存：


标题。

正文。

来源。

发布时间。

链接。

AI分析结果。

质量状态。



重要字段：


sourceUrl

verified

dataStatus

duplicateHash

sourceCount



注意：

不要直接删除历史新闻。



================================

# 3. DailyReport


用途：

每日AI产业报告。



保存：


日期。

日报内容。

生成状态。



================================

# 4. NewsEvent


用途：

新闻事件聚合。



作用：

多个新闻形成一个产业事件。



例如：


多个模型发布新闻

↓

一个模型发布事件



重要字段：

heatScore



================================

# 5. IndustryTrend


用途：

记录产业趋势。



例如：


AI Agent

多模态模型

机器人



================================

# 6. BusinessOpportunity


用途：

记录AI商业机会。



内容：

机会方向。

市场分析。

相关行业。



================================

# 7. Investment


用途：

投资观察。



记录：


企业。

投资事件。

分析结果。



================================

# 8. InvestmentScore


用途：

投资评分。



用于：

企业评价。



================================

# 9. InvestmentFavorite


用途：

用户收藏投资对象。



================================

# 10. BusinessReport


用途：

商业分析报告。



================================

# 11. RSSLog


用途：

记录采集过程。



用于：

排查采集问题。



================================

# 12. IndustryHotspot


用途：

记录行业热点。



================================

# 13. PageView


用途：

访问统计。

# 数据修改规则


禁止：

直接修改生产数据库。


禁止：

删除大量历史数据。



正确流程：


修改schema


↓

生成migration


↓

测试


↓

部署



================================

# AI维护注意事项


修改数据库前必须确认：


1.

影响哪些模块。


2.

是否需要迁移。


3.

是否影响已有数据。


4.

是否需要备份。



================================

# 数据质量要求


所有核心数据：


必须有来源。


必须可追溯。


必须避免重复。
