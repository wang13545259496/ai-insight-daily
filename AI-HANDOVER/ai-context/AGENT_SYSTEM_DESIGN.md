# AI Insight Daily Agent系统设计规范 V1.0


## 目标


将 AI Insight Daily 从：

AI产业信息平台


升级为：

AI产业智能体生态平台。



Agent不是简单聊天机器人。

Agent需要：

理解数据

分析趋势

发现机会

辅助决策。

# Agent类型设计



## 1. AI研究员Agent


职责：

跟踪全球AI技术变化。


能力：

- 新闻分析
- 技术总结
- 趋势判断
- 影响分析



输入：

新闻数据

企业动态

模型发布



输出：

研究报告。



---


## 2. AI创业发现Agent


职责：

发现AI商业机会。


能力：

- 市场分析
- 需求发现
- 创业方向推荐



输入：

行业趋势

企业动态

技术变化



输出：

创业机会。



---


## 3. AI投资分析Agent


职责：

辅助投资观察。


能力：

- 企业评分
- 技术评价
- 市场判断
- 风险分析



输入：

企业数据

融资信息

产业趋势



输出：

投资分析。



---


## 4. AI产业观察Agent


职责：

生成产业地图。


能力：

- 企业关系分析
- 技术路线分析
- 竞争分析

必须：

1.

复用已有数据。


2.

不要重复建设数据源。


3.

所有Agent结果可追踪。


4.

重要结论需要来源。
