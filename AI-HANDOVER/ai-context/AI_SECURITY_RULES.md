# AI Insight Daily AI安全与权限规范 V1.0


## 核心原则


AI可以辅助开发和分析。

但是：

生产环境关键操作必须可控。



原则：

自动化提高效率。

人工保证安全。



================================

# AI权限等级


## Level 1：允许自动执行


包括：


读取代码。


分析日志。


生成报告。


检查项目状态。


分析数据库结构。


生成优化建议。



--------------------------------

## Level 2：需要确认后执行


包括：


修改代码。


修改配置文件。


增加依赖。


修改Prompt。


调整AI分析规则。


创建数据库Migration。



执行前必须说明：

修改原因

影响范围

风险。



--------------------------------

## Level 3：禁止自动执行


包括：


删除生产数据。


直接修改生产数据库。


删除核心模块。


修改服务器安全配置。


关闭安全服务。


泄露环境变量。



================================

# 数据安全规则


禁止：

提交：

.env


API Key


密码


Token


服务器敏感信息



数据库操作：


禁止：

直接操作生产SQLite文件。


正确流程：


修改Schema

↓

Migration

↓

测试

↓

部署



================================

# AI生成内容安全


AI输出必须：


区分：

事实

分析

预测



禁止：


编造来源。


虚构数据。


伪造引用。



================================

# 新闻数据安全


采集内容必须经过：


来源检查

↓

质量检测

↓

重复检测

↓

AI分析



不能：

未经验证进入核心知识库。



================================

# Agent安全规则


未来Agent：


必须：

记录操作日志。


保存数据来源。


限制工具权限。


重要操作人工确认。



================================

# 生产环境规则


修改生产环境前：


必须：

1.

确认当前版本。


2.

备份。


3.

测试构建。


4.

记录CHANGELOG。



================================

# 回滚规则


任何重大升级必须支持：


代码回滚。


数据库恢复。


配置恢复。



================================

# AI维护要求


AI助手必须：


先阅读：

PROJECT_MEMORY.md


再阅读：

AI_SECURITY_RULES.md



任何违反安全规则的操作：

必须停止并请求确认。
