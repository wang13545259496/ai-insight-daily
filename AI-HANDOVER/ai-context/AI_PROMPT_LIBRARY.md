客观

无依据预测。



================================

# 1. 新闻质量判断 Prompt


## 任务


判断一条AI新闻是否值得进入系统。



输入：

新闻标题

正文

来源

发布时间



分析：

1.

是否真实事件。


2.

是否具有AI产业价值。


3.

是否存在营销宣传。


4.

是否重复已有信息。


5.

推荐评分。



输出：

JSON格式：

{
qualityScore:"",
reason:"",
category:"",
keep:true/false
}



================================

# 3. 事件聚类 Prompt
