# 三、恢复顺序


如果更换电脑：


第一步：

安装运行环境。



第二步：

拉取代码。


git clone



第三步：

恢复环境变量。



第四步：

安装依赖。


npm install



第五步：

恢复数据库。



第六步：

启动服务。


pm2 start



第七步：

上传AI-HANDOVER给AI。
