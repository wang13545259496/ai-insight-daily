# AI Insight Daily AI知识库设计规范 V1.0


## 目标


建立属于 AI Insight Daily 的 AI产业知识库。


让AI不仅知道：

当前新闻。


还知道：

过去发生什么。

为什么发生。

未来可能产生什么影响。



================================

# 知识库总体结构


AI产业知识库


├── 新闻知识

├── 企业知识

├── 技术知识

├── 模型知识

├── 投资知识

├── 产业趋势知识

└── Agent知识



================================

# 1. 新闻知识库


来源：

News表


保存：

- 新闻标题
- 正文
- 来源
- 发布时间
- 企业
- 技术方向
- 影响分析


用途：

支持：

研究Agent

趋势分析Agent



================================

# 2. 企业知识库


目标：

建立AI企业数据库。


包括：


企业名称

所属国家

主营方向

核心产品

技术能力

融资情况

竞争关系



例如：


OpenAI

Google DeepMind

Anthropic

百度

腾讯

字节跳动



用途：

企业分析。

产业地图。



================================

# 3. 模型知识库


记录：


模型名称

开发公司

发布时间

参数规模

能力特点

应用场景

性能变化



用途：

模型趋势分析。



================================

# 4. 投资知识库


记录：


公司

融资事件

投资机构

金额

领域

市场评价



用途：

投资Agent。



================================

# 5. 产业趋势知识库


记录：


趋势名称

相关企业

相关技术

商业影响



例如：

机器人

# 数据来源原则


优先：

权威媒体
