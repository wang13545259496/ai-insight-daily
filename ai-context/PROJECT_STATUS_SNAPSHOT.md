# 能力增强（2026-10-13）


## 旅行规划 Agent 接入高德地图


新增：


- 活动坐标与规范地址
- 真实通勤（方式 / 距离 / 耗时），多方式对比取最快
- 逐日天气预报
- 行程布局校验与一次自动重排


配置：

AMAP_WEB_KEY（未配置时静默跳过，功能降级但不报错）


实测（北京 → 三亚，5 天）：


12 段通勤，最长 48 分钟，超限 0 段。

重排机制触发一次，布局问题由 2 处降到 0 处。


已知限制：


1. 高德仅覆盖中国境内，境外行程不含地图信息
2. 天气预报仅覆盖未来数日，行程日期超出时不展示并告警
3. POI 搜索与天气查询免费额度为 5000 次/月

和风天气注意事项：


1. QWEATHER_HOST 必填，取自控制台「设置 → API Host」，
   形如 https://xxxxx.re.qweatherapi.com。
   缺它返回 403 Invalid Host。

2. 请求必须带 lang=zh，否则返回当地语言。

3. 控制台"无免费额度的 API"（热带气旋、海洋、辐照）
   不要启用，否则任何请求都会计费。
