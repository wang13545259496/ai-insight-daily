# AI Insight Daily AI模型接入规范 V1.0


## 目标


建立模型无关的AI架构。


支持：

OpenAI

DeepSeek

Claude

Gemini

未来其他模型



核心原则：

业务逻辑不依赖单一模型。



================================

# AI调用架构


业务模块


↓

统一AI接口层


↓

模型适配层


↓

具体模型API



结构：


新闻分析

↓

AI Client

↓

DeepSeek / GPT / Claude



================================

# 模型切换原则


禁止：


业务代码直接调用某个模型。



错误方式：


newsAnalyzer.ts

直接调用：

gpt-4


正确方式：


newsAnalyzer.ts

调用：

AI Service



由配置决定：

使用哪个模型。



================================

# 配置方式


环境变量：


AI_PROVIDER


例如：


deepseek


openai


claude



AI_MODEL


例如：


deepseek-chat


gpt-4


claude-sonnet



================================

# AI任务分类

## 产业分析

谨慎。

================================

# API安全


禁止：

代码中保存API Key。



必须：

使用：

.env


例如：


DEEPSEEK_API_KEY


OPENAI_API_KEY



================================

# 模型评估

2.

分析准确性。


3.

成本。


4.

响应速度。


5.

稳定性。
